## الحالات المدعومة:

### 1️⃣ من صفحة نموذج المريض (الحالة المثالية)
```
PatientForm → [Save] → AppointmentBooking
                        ✓ patientFormId مملوء
                        ✓ patientName معروض فقط
                        ✓ يتم الإرسال تلقائياً
```

### 2️⃣ من URL مباشر مع query parameters
```
/appointments/new?patientFormId=507f&patientName=أحمد
                        ✓ يتم استقبال البيانات من URL
                        ✓ patientFormId مملوء
```

### 3️⃣ دون patientFormId (حجز عام)
```
/appointments/new
                        ✓ يمكن إدخال اسم المريض يدويًا
                        ✓ استخدام patientName بدلاً من patientFormId
```

## أمثلة على الفحوصات:

```javascript
// في AppointmentBooking.jsx

// التحقق من صحة معرّف MongoDB
const hasPatientFormId = isMongoObjectId(patientFormId);
// يتوقع: "507f1f77bcf86cd799439011" → true
// يتوقع: "" → false

// عند الإرسال
if (hasPatientFormId) {
  // استخدام patientFormId
  appointmentPayload.patientFormId = patientFormId;
} else {
  // استخدام patientName
  appointmentPayload.patientName = patientName.trim();
}
```
